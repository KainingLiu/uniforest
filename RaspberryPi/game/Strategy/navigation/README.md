# 参数化位置间导航

本目录保留独立的全场位置间规划/仿真研究代码，已不作为比赛--enable-motion-planning后端。
2026-10-03比赛入口改为原动作局部平滑，并在现有Tag6接近中融入相对视觉修正；见[实际运行说明](../optimizations/MOTION_PLANNING.md)。
下文只描述本目录的独立接口与历史仿真条件，不能据此判断比赛启动需要全场Tag或名义地图起点。

## 使用方式与职责

`FieldPlanner(field, robot).plan(source, target, actual_start=pose)` 返回完整路线。
`Location(family, along, gap_mm)` 的 along 是合法沿墙区间的连续比例 [0,1]，gap_mm 是车体外包与操作墙面的间距 [0,120] mm。
位置包括启动墙角、地面橙块墙、高台橙块墙、紫块墙、搭建操作带和 Tag2～Tag6 观察入口。
Tag1 现有配置与规则图位置冲突，未虚构一个可用入口。红方半场尚未增加镜像适配。

沿墙两端按整车宽度和 35 mm 侧边余量确定；紫块区使用可站稳的高台墙面，坡道侧面不当作平面取块位置。
搭建目标是车体在搭建台前的操作姿态，不能把机器人中心放进实体搭建台。
请求超出可达区间、穿墙初始姿态或不支持的地图几何会明确拒绝，不自动吸附到演示点。
零间距目标在 5 mm 到位容差内停在墙面自由侧，最后约 3 mm 留给单独的接触操作；不模拟刚体穿墙或顶墙接触力。

实际抓取结束后传入 `actual_start`；`locate()` 会从位姿恢复沿墙位置与离墙距离，整段离场路线由这个实际起点生成。
源位置不必回到固定点。入口目前要求静止，跨两个独立导航调用的非零速度接管仍由后续动作编译处理。

## 路线与控制

- 位置集合只定义操作目标，不规定中途经过点。使用整车位姿空间 (x,y,yaw) 搜索，动作包含平移、转向及平移转向同时发生；坡道姿态来自地形约束。
- 搜索网格为 100 mm / 30°，仅用于数值求解。连续端点连接、按通行耗时判断的可见性捷径及五次曲线优化消除网格路径的多余拐点。
- 同时保留直达候选、简化后的搜索路径和原可行路径，比较不同圆滑范围的时间参数化结果，选择预计耗时较短的可行曲线。没有固定通道中间点或强制返归点；不保证数学上的全局最优。
- 航迹采用直线和五次 Bezier 圆滑段；圆滑段端点曲率为零，按照弧长密集采样。保留中间速度，整段终点停车。
- 航向独立于平移方向；比赛终点航向沿用原路线，depart_b保留180°终点朝向。
- 允许转向与平移同步的搜索动作，以及沿自由运动区间展开航向变化的候选；整车姿态不满足净空时保留受控低速转向。
- 使用完整非对称车体矩形对场地障碍做 SAT 分离检查，覆盖长车头旋转扫掠。绕行与转向空间不满足时拒绝路线。
- 参考速度受墙面余量、曲率、角速度、角加速度、前向与反向制动约束。实际执行器额外限制指令加速度和加加速度，并按速度、制动能力与延迟前瞻整车余量，包含加速度反向、轮电机滞后及降速时间。
- 跟踪滞后时平滑放慢参考时钟，防止理想时间线继续向前跑。近墙制动考虑执行器滞后和一帧延迟，安全限幅优先于舒适性。
- 近墙降速状态保持到余量不再下降且前瞻稳定，避免减速令短时预测变好后立即重新加速。平移、角速度和由经典指令包络推导的单轮 RPM 上限同时作用于实际输出。
- 新视觉定位表明机器人已超过旧参考位置时，将剩余参考投影到修正后的实际进度，避免倒退追赶过时的时间点。
- 高速定义为实测平移速度大于 300 mm/s；离线验证要求该阶段整车到障碍的保守余量至少 100 mm。

当前运动参数从比赛配置读取，长距离设定默认由 1000 提高到 1100 mm/s（1.10×）；
短距 400、坡道 800、沿墙搜索 300、朝墙接近 150 mm/s 保留各自来源。
经典速度前馈之外存在位置 PID 预算，新参考时序也考虑这一预算；不能把设定速度误称为实际峰值。
加速使用原三次平滑规律，制动距离沿用原编码器比例。附加曲率、轮速、响应提前量和墙面约束统一作用于规划和执行。
新增世界坐标 X/Y 与航向位置 PID：轨迹速度前馈＋P/I/D 误差修正；D 使用速度误差并滤波，I 有分离、限幅及外部饱和回退。
普通到位沿用 8 mm 窗口并预留 1 mm 模型定位误差；搭建仍要求 5 mm、低速稳定及视觉证据。
参数来源、完整开关与测试入口见[运动规划模块](../optimizations/MOTION_PLANNING.md)。

`elapsed_s` 为四轮模型积分时间，包含运动与到位等待，不包含规划计算或网页渲染耗时；动画倍速只改变回放。
模型时间、速度、误差及无碰撞结果仍需实机校准，不能据此报告真实比赛提速比例。
规划器、执行器和模拟器共享同一运动参数对象；`simulation.linear_comparison` 在同一底盘上重放经典真实控制循环作对照。

## 移动 Tag6 与建筑末端条件

Tag6 在整段运动中持续读取，没有到达固定 425 mm 定位点再启动 PID 的步骤。
观测包含采集时刻、坐标系、标定状态、误差指标；利用对应时刻的里程计历史计算 SE(2) 修正，再推算当前位置。
拒绝过期、未来、重复、未标定和大幅跳变帧。收到至少三个有效 Tag6 帧才满足初始定位条件。
参考目标始终是实际建筑操作位姿，定位更新经同一个有速度变化限制的控制器修正，不插入另一套底盘 PID。

搭建到达要求：位置/航向/实测低速连续满足条件，已有 Tag6 定位，且至少三帧末端建筑观察仍新鲜。
没有 Tag6 时，先完成可观察朝向，再在近目标区受控等待；超时停止并报告需要返回观察区。
目前不会自动执行观察区往返重试。建筑视觉缺失也停止，`build_ready=False`；本模块自身从不触发 Build。
一次 Tag6 锁定后，近距离建筑观察可以继续修正误差；模型没有实现完整协方差传播、对手预测或全局时间最优求解。

`vision/opencv/field_localizer.py` 新增 `captured_monotonic`，记录图像从驱动读出的主机时刻。
它早于检测和滤波，实际曝光/驱动缓存延迟通过 `NavigationCalibration.capture_delay_s` 单独标定。
真实适配器使用单 Tag6 的原始解算，避免把跨帧 EMA 输出当作当前曝光位姿；建筑观察复用现有顶部几何与目标跟踪。

## 实机接入边界

`RobotNavigation(robot, context, planner, calibration, building_controller=...)` 复用现有轮速接口、取消和通信检查。
调用方持有策略互斥并提供已知起点；要求机构动作已结束且底盘静止，后续调用应使用上次测得的结束位姿。
导航失败关闭本次上下文并尝试急停，通信恢复不会自动继续。`NavigationCalibration` 无已验证记录时在发送动作前拒绝。
当前 Tag 相机配置的 calibrated 仍为 false，不能据此声明实机移动定位已经可用。
CompetitionRoutes与标定JSON属于独立研究接口；比赛入口不会选择它，也不接受--navigation-config。
仿真继续保留本目录的规划与控制，以便独立研究；当前比赛行为以LocalRoutes及tag_approach为准。

本轮协议未变：0x10/8 B 轮速、0x80/80 B 遥测、0x83/11 B 动作状态、数值大端/CRC 小端和 200 ms 失联阈值保持。
工作区已有的独立扩展协议改动保留，本轮未改固件、烧录或部署。

## 仿真与验证

当前 1.10× 巡航与位置 PID 版本（2026-10-02）：406 项测试、165 文件语法与导入检查通过。
377/377 场景通过，模型内碰撞 0，高速最小余量 124.50 mm；普通路线终点 <8 mm、搭建 <5 mm。
位置间导航的 PID 误差、修正量和积分量会进入仿真轨迹；参数见 `tracking.TrackingGains`。
现场相机、机械包络和响应仍需确认，未部署。下位机 Debug 配置受 ARM GCC 缺失阻挡。

```bash
python -m simulation.navigation_server --port 8766
python -m simulation.navigation_verify
python -m unittest tests.test_field_navigation -q
```

访问 `http://127.0.0.1:8766/simulator.html`。任意滑条值都会在服务器调用规划器与四轮闭环模型重新计算，动画回放实际积分轨迹。
可选 Tag6 丢失、短时遮挡、异常帧、建筑视觉缺失、观测延迟、里程计偏差；任何失败保留失败位姿及碰撞指标。
验证报告包含全部位置族两端/中间的有向组合、固定种子随机点及视觉场景，保存到 `simulation/output/navigation-verification.json`。
中途停车指标要求平移小于 5 mm/s、转动小于 1°/s 同时持续 120 ms，排除起终点；原地转动不当作整车停止。
有限测试不能证明无限连续集合或真实比赛的绝对无碰撞；每条请求仍单独检查几何和执行状态。
模型尚无三维机构、俯仰/重力、接触力和对手；实机验证需使用测量后的车体与场地数据。

历史低速模型验证：377/377 场景通过（324 代表点有向配对、48 随机位置、5 视觉情形），
模型内碰撞为 0，高速段最小余量 108.56 mm，到达场景最大误差 3.85 mm。
全量 394 项无硬件测试、157 文件语法与导入检查通过；ARM GCC 缺失，未部署或实机运行。
