# 方块可见轮廓六点重标注与微调报告

日期：2026-09-29。模型处于本机离线验证阶段，尚未部署到树莓派或接入比赛策略。

## 标注语义与数据

沿用 `collection_20260926` 的 418 张原始 `cube` 摄像头图片，以及逐图审过的方块实例/颜色标签。新增每块六个图像平面关键点：顶面后左、后右、前右、前左，以及正面下左、下右。只连接能在画面中确认的顶面/正面边。方块超出画面时，将越界一侧关键点的可见性设为 0；训练标签不含隐藏边、真实深度或三维坐标。

候选关键点由实例掩膜内的亮度分层与外轮廓提取生成。审阅了全部 27 张联系表（覆盖 418 张图片），并在原始 640×480 尺寸复核 17 张质量标记图。审阅记录在 [VISIBLE_OUTLINE_V2_REVIEW.json](VISIBLE_OUTLINE_V2_REVIEW.json)。这轮没有逐点手工移动关键点；这些标签属于**算法提议、视觉复核的半自动标注**，其像素级准确度仍受原有实例掩膜和顶/正面亮度分界影响。原先排除的 82 张不可靠图片继续排除。

保持原有近重复隔离：训练 229 图、303 块；验证 30 图、37 块；独立测试 29 图、57 块。另有 48 张已审核图片隔离不用。数据集保存在本地忽略目录 `data/collection/visible_outline_v2/`，包括 `reviewed_visible.jsonl`、YOLO pose 标签、划分清单和 YAML。原始图片及训练数据不提交 Git。

## 训练与验证

从官方 `yolo11n-pose.pt` 预训练权重开始，先冻结前 10 层训练 8 轮，再全部解冻微调 50 轮；320 像素输入、批量 16、AdamW，禁用色相扰动和 Mosaic。训练脚本为 [train_visible_outline.py](../scripts/train_visible_outline.py)，环境为 Ultralytics 8.4.163、PyTorch 2.11.0+cu128、RTX 5070 Laptop GPU。按验证集选择解冻阶段的 `best.pt`，复制为本地 `models/cube_visible_outline_v2.pt`。权重 SHA-256：`595f5c7c879cf03de53aa55d834f86adbb25fe84a437f65d541c6f8f76b53e2e`。

| 指标 | 验证集 | 独立测试集 |
| --- | ---: | ---: |
| 图片 / 实例 | 30 / 37 | 29 / 57 |
| 框 mAP50–95 | 0.867 | 0.842 |
| 关键点 Pose mAP50–95 | 0.773 | 0.784 |
| 目标数完全一致的图片 | 30 / 30 | 29 / 29 |
| 匹配实例的可见关键点平均误差 | 17.1 px | 19.5 px |
| 可见关键点误差 P95 | 60.6 px | 63.4 px |

以上关键点像素误差只统计检测框匹配、且关键点可见置信度 ≥0.5 的点；相机原图为 640×480。测试集在该阈值下，可见性判断为 TP 239、FP 15、FN 16、TN 72。Pose mAP 使用新的六点标签，不能与此前四点加 PnP 的 0.899 直接比较。

同一权重在验证集以 416 和 640 像素输入推理时，Pose mAP50–95 分别降至 0.692 和 0.042。另从同一预训练权重独立微调了 416 输入模型：验证 Pose mAP50–95 升至 0.816，然而可见性误判增加到 FP 35（320 模型为 FP 8）；截断方块的叠图常画出画面外边。将 416 模型阈值提高到 0.7 后，FP 降到 9，但漏点 FN 升到 40。以**只画实际可见边**为验收重点，最终保留 320 模型和 0.5 阈值。改变输入尺寸不能替代增加多场景标签。

对照图保存在 `runs/visible_outline_v2/test_selected_kpt05/comparisons/`，左侧是审核标签，右侧是模型输出。逐张查看四张测试联系表后，完整方块与紫色方块多数边线贴合；连续橙色方块和画面边缘的截断目标仍会出现缺线、错误延长的线或额外关键点。测试中未观察到图级目标数量错误，但样本主要来自同一批次，不能据此推断新场地、强遮挡、建筑堆叠和实机抓取精度。部分标签来自亮度分界，极暗或反光场景仍需人工逐点校准。

## 复现与试图

依次运行 `scripts/propose_visible_outline.py`、审阅并更新 `docs/VISIBLE_OUTLINE_V2_REVIEW.json`、运行 `scripts/finalize_visible_outline.py`、`scripts/train_visible_outline.py`，最后用 `scripts/evaluate_visible_outline.py` 对验证和测试划分生成指标与左右对照图。脚本默认路径相对于本目录；已有输出需换新目录以保留审阅记录。对新图片可运行：

```powershell
& .venv/Scripts/python.exe scripts/predict_visible_outline.py --source path/to/images --output path/to/outlines
```

输出含叠图和逐实例关键点 JSON；默认关键点可见置信度阈值为 0.5。可见轮廓仍属于二维投影。测量隐藏面、实际三维姿态和毫米抓取位置需要额外标定/几何约束和有真值的实机验证。这版暂不触发机器人动作。

协议未变：Python 与 A 板的命令编号、载荷长度、字节序、遥测布局和 200 ms 通信失联急停均未修改。
