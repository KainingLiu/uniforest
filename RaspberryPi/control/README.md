# 底盘与运动控制

2026-10-05 按本地源码整理。路线见[策略说明](../Strategy/README.md)，机构动作见[动作表](../../Uniforest_A/ACTIONS.md)。
下列数值是软件配置，不代表实际车速或停止距离。

## 分层与参数来源

- A 板 `motor3508.c` / `main.c`：1 kHz 四轮速度环和 CAN 反馈累计。
- `control/chassis.py`：20 ms 位置外环、速度规划、IMU 航向保持和停止。
- `Strategy/competition.py`：路线加速选择、顶墙与任务降级。
- 各 `Task*Config`：距离、方向、等待和局部速度覆盖。

| Task0、Task1 运输、Task3-1/2/3 返程长横移 | 1000 mm/s | 800 ms |
| Task2 上下坡段 | 800 mm/s | 800 ms |
| Task2 补偿实际距离 ≥500 mm | 800 mm/s | 800 ms |

公共常量为普通速度/加速 `400/300`、长距速度/加速 `1000/800`。
补偿距离包含搜索后的实际净横移，不能只按配置基础量判断快慢段。

## 提前减速与到位

比赛定距使用 `route_mode=True`：前馈取时间加速和剩余距离减速曲线的较小值，短段也能提前减速。
进入 ±8 mm 估计距离窗口后发四轮零速并清除积分；滑出窗口则恢复有符号纠偏。
位置合格且四轮反馈绝对值均 ≤50 RPM，按新遥测完成确认后结束；重复帧不累计。
短于 16 mm 的补偿使用不超过半程的容差，路线通常 `hold_ms=0`。

手动/Agent 单次定位默认 `route_mode=False`，保留编码器窗口和原定位行为。
横移系数 `500/465` 来自此前地胶测量，不能消除所有场地下的滑移。
超时预算为 `max(2000 ms, 预计匀速时长 + accel_ms + hold_ms + 2000 ms)`。
策略可接受超时但编码器进度 ≥90% 的结果；取消、通信丢失、陈旧遥测或进度不足不适用。
零速进入下位机速度闭环；指定载荷和地面的停止距离需要实测。

## 转向

任务路线传入 120°/s，常规加速 600 ms，容差 ±1.5°，最低非零期望 8°/s。
通用 `TURN_BASE_SPEED_DEG_S=90` 是控制器基准，不是当前路线传入速度。
路线通常一次到位确认、无额外保持。超时诊断与既有降级保留；通信和机构异常仍中止。

## 顶墙

阈值来自 `FirstTaskConfig`，计时由 `StallConfirmation` 处理。

| 参数 | 常规顶墙 | 抓取短压墙 |
| --- | ---: | ---: |
| 速度 | 300 mm/s | 150 mm/s |
| 超时 | 2.5 s | 1.0 s |
| 单轮绝对轮速上限 | 240 RPM | 120 RPM |
| 单轮绝对电流下限（原始反馈值） | 1800 | 1800 |
| 起步保护 | 500 ms | 300 ms |
| 有效确认 | 300 ms | 200 ms |
| 短暂丢条件容许 | 80 ms | 80 ms |

单轮须同时满足轮速和电流条件；向前检查两个后轮，横向要求四轮中至少三轮。
起步保护不累计确认；丢条件期间暂停，超过 80 ms 清零，成功必须发生在满足条件的新遥测帧上。
默认顶墙超时先停车，再按成功继续；`wall_timeout_is_success=False` 可要求超时报错。

短压墙与 Grap 同时启动，结束只停底盘。Grap1/3 等机构完成，Grap2 在压墙结束且回程上升达到 5 cm 后可并行后续路线。
Task1 投放顶墙后按当前姿态为 180°更新软件零点；初始橙块顶墙按 0°更新，不改变 IMU 硬件标定。

## 故障与验证

通信断开、急停、陈旧遥测、发送失败和机构故障不会转换为“到位”或“视觉降级”。
A 板独立保留 200 ms 失联保护，恢复通信不续跑。
检查见 `tests/test_chassis_route.py`、`tests/test_wall_contact.py` 及策略回放。
本轮整理协议未变，控制参数未改；历史调参与回退见 [CHANGELOG.md](../CHANGELOG.md)。
